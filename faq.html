FAQ (Tanya Jawab)

Temukan jawaban untuk pertanyaan umum mengenai layanan SMART O²².

1. Apa itu SMART O²² Finance Assistant?

SMART O²² Finance Assistant adalah produk pertama dari platform otomasi SMART O²², berupa asisten pencatat keuangan berbasis AI. Produk ini memungkinkan Anda untuk mencatat transaksi, melihat laporan keuangan, dan mendapatkan insights (analisis pengeluaran) langsung melalui WhatsApp dan Web Dashboard yang saling tersinkronisasi.

2. Bagaimana cara kerja Finance Assistant?

Setelah Anda berlangganan, Anda akan mendapatkan instruksi untuk mengakses SMART O²² Finance Assistant melalui WhatsApp. Anda cukup mengirim pesan teks, merekam *voice note*, atau mengirim foto struk untuk mencatat transaksi Anda. Data tersebut akan diproses secara otomatis oleh sistem kami dan dapat diakses kapan saja melalui WhatsApp maupun Web Dashboard.

3. Apakah WhatsApp dan Dashboard tersinkronisasi?

Ya. Kedua antarmuka menggunakan catatan keuangan yang sama (*shared financial records*). Pencatatan cepat dapat dilakukan melalui WhatsApp, sementara untuk melihat visualisasi data, mengubah (*edit*), atau menghapus transaksi dapat dilakukan dengan mudah melalui Web Dashboard.

4. Bagaimana cara mengakses Web Dashboard?

Anda cukup mengirimkan perintah /login ke Asisten WhatsApp. Sistem akan mengirimkan tautan Web Dashboard beserta kode OTP sementara. Masukkan nomor WhatsApp dan kode OTP tersebut di halaman login untuk masuk ke Dashboard.

5. Berapa harga berlangganan layanan ini?

Kami menawarkan paket berlangganan dengan harga yang terjangkau: Paket Basic (Rp 17.900/bulan), Paket Pro (Rp 28.900/bulan), dan Paket Premium (Rp 34.900/bulan). Pembayaran dilakukan melalui saluran pembayaran (*Payment Gateway*) resmi secara prabayar.

6. Berapa lama data saya disimpan setelah berhenti berlangganan?

Data Anda akan disimpan selama tiga bulan kalender setelah langganan Anda berakhir. Jika Anda memperpanjang langganan selama periode retensi ini, catatan Anda sebelumnya akan tetap tersedia dan dapat aktif kembali. Jika Anda tidak memperpanjang langganan hingga akhir periode retensi, catatan keuangan yang terkait dengan akun Anda dapat dihapus secara permanen dari database aktif.

7. Apakah SMART O²² bertindak sebagai penasihat keuangan?

Tidak. SMART O²² Finance Assistant menggunakan teknologi AI untuk merangkum dan menganalisis data transaksi yang Anda berikan. Asisten ini tidak bertindak sebagai penasihat investasi, penasihat keuangan bersertifikat, ataupun akuntan profesional.
