Panduan Singkat

Cara Mudah Menggunakan SMART O²

1 WHATSAPP COMMANDS

Daftar perintah yang dapat digunakan di WhatsApp untuk berinteraksi dengan asisten:

  • TRANSACTIONS
  • /catat ➔ Mencatat transaksi masuk/keluar.
  • /riwayat ➔ Cek transaksi hari tertentu.

  • FINANCIAL OVERVIEW
  • /saldo ➔ Mengecek total saldo saat ini.
  • /kategori ➔ Cek ringkasan per kategori.

  • ACCOUNTS
  • /bank ➔ Cek saldo akun Bank.
  • /ewallet ➔ Cek saldo akun E-Wallet.

  • PLANNING
  • /budget ➔ Mengelola batas pengeluaran bulanan.
  • /tabungan ➔ Cek saldo tabungan & investasi.

  • DEBT
  • /utang ➔ Kelola catatan utang.
  • /piutang ➔ Kelola catatan piutang.

  • DASHBOARD
  • /login ➔ Meminta kode OTP untuk Web Dashboard.

Catatan: Manajemen transaksi lebih lanjut seperti Edit dan Hapus dapat diakses melalui Web Dashboard.

2 NATURAL AI CONVERSATION

Selain menggunakan slash commands (/), Anda dapat berkomunikasi secara natural dengan Asisten untuk mendapatkan AI financial insights dan spending analysis.

Contoh:

  • "Berapa pengeluaran saya bulan ini?"
  • "Saya paling banyak menghabiskan uang untuk apa?"
  • "Berapa saldo saya?"
  • "Bagaimana pengeluaran saya bulan ini?"

Asisten AI membaca data yang Anda catat untuk memberikan ringkasan (overview). Asisten ini bukan penasihat investasi atau akuntan berlisensi profesional.

3 INPUT METHODS (TEXT, PHOTO, VOICE)

Tersedia 3 metode pencatatan transaksi yang didukung:

  • TEXT: Ketik teks biasa.
    Contoh: /catat makan 50rb
  • PHOTO / FILE: Kirim foto struk atau dokumen invoice PDF.
    Syarat: Anda wajib mengetikkan /catat pada kolom caption.
  • VOICE NOTE: Rekam suara Anda.
    Syarat: Rekaman wajib diawali dengan kalimat "Ayo catat" diikuti detail transaksi.
4 FITUR BUDGETING

Atur batas pengeluaran untuk setiap kategori. (Contoh: /budget Makan 500rb)

Sistem akan memantau pengeluaran Anda dan mengirimkan peringatan (budget warnings) saat pemakaian mencapai ambang batas tertentu: 60%, 70%, 80%, 90%, dan 100%.

"Stay aware of your spending before you exceed your budget."

5 WEB DASHBOARD & LOGIN OTP

Akses Web Dashboard untuk antarmuka visual yang mencakup: financial overview, manajemen transaksi, visualisasi grafik dompet/kategori, pengaturan budget, dan fitur Excel export.

Alur Login Dashboard:

  • Kirim perintah /login ke Asisten WhatsApp.
  • Asisten akan merespons dengan kode OTP sementara.
  • Asisten juga akan mengirimkan Link Dashboard.
  • Buka link tersebut, lalu masukkan nomor WhatsApp dan kode OTP Anda.
  • Anda berhasil mengakses dashboard Anda.
