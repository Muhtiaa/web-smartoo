Panduan Singkat

Cara Mudah Menggunakan SMART O²

1 KETIK /MENU

Perintah ini adalah gerbang utama Anda. Menampilkan daftar perintah yang bisa Anda gunakan. Di bawah ini adalah daftar 14 command SMART O² - PRO:

  • /menu ➔ Mengecek daftar perintah.
  • /saldo ➔ Mengecek total saldo saat ini. (Contoh: /saldo atau Cek saldo berdasarkan tanggal /saldo 27 juli)
  • /catat [Keterangan] ➔ Mencatat transaksi. (Contoh: /catat beli makan 50rb tunai, terima gaji 14jt BCA, naik ojek 20rb Gopay, dapat bonus 500rb BCA, dst)
  • /riwayat [Tanggal] ➔ Cek transaksi hari tertentu. (Contoh: /riwayat 3 april)
  • /hapus [Keterangan] ➔ Menghapus catatan. (Contoh: /hapus 28 juli bensin)
  • /kategori [Jenis] ➔ Cek pengeluaran khusus. (Contoh: /kategori makan)
  • /bank ➔ Cek saldo Bank apabila mencatat.
  • /ewallet ➔ Cek saldo E-Wallet apabila mencatat.
  • /tabungan ➔ Cek tabungan & investasi.
  • /edit [Keterangan] ➔ Memperbaiki catatan. (Contoh: /edit 28 juli makan jadi 60rb)
  • /export ➔ Download Laporan Excel.
  • /utang [Keterangan] ➔ Daftar utang.
  • /piutang ➔ Daftar piutang.
  • /budget [Kategori] ➔ Set batas pengeluaran. (Contoh: /budget Makan 500rb)
2 KETIK /CATAT

SMART O² mendukung 4 cara revolusioner untuk mencatat transaksi keuangan Anda secara fleksibel:

  • Catat via Chat Biasa: Ketik perintah langsung di chat.
    Contoh: /catat beli kopi 30rb cash, gajian 14jt BCA, dan seterusnya.
  • Catat via Voice Note: Rekam suara Anda.
    Syarat: Ucapkan di awal kalimat dengan jelas "AYO CATAT" diikuti beli kopi 30rb cash, dll.
  • Catat via Gambar/Foto: Upload foto struk belanja Anda.
    Syarat: WAJIB sertakan caption teks: /catat, maka SMART O² akan membacanya otomatis.
  • Catat via File Dokumen: Upload file invoice atau struk PDF Anda.
    Syarat: WAJIB sertakan caption teks: /catat, maka SMART O² akan mengekstrak isinya.
3 DAFTAR KATEGORI

Sistem AI kami telah dilatih untuk secara otomatis mengklasifikasikan transaksi Anda ke dalam kategori baku yang ada di sistem, antara lain: Makanan, Minuman, Transportasi, Belanja Bulanan, Gaji, Bisnis, Hutang, Piutang, Hiburan, Listrik, Internet, Kesehatan, dan puluhan kategori lainnya. Anda hanya perlu mencatat natural, dan AI akan menentukan kategorinya.

4 SMART O² MEMPROSES

Mesin kecerdasan buatan (AI) kami akan mengeksekusi catatan Anda secara instan. Ia mendeteksi niat, menyaring nominal angka, mencocokkan metode pembayaran (Cash, Bank, e-Wallet), lalu menyimpannya secara aman di *Cloud Database*. Dalam hitungan detik, Anda akan menerima balasan konfirmasi bahwa uang Anda telah rapi tercatat di pembukuan.

5 DASHBOARD KEUANGAN

Bagi pengguna Pro & Premium, nikmati visualisasi arus kas Anda melalui Web Dashboard kami dengan langkah berikut:

  • Kirim pesan /login ke bot WhatsApp SMART O².
  • Bot akan membalas dengan memberikan 6 digit kode OTP yang bersifat rahasia dan sementara.
  • Buka halaman Dashboard (klik tombol DASHBOARD di menu navigasi atas website ini).
